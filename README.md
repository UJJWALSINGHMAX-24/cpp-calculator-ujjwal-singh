# C++ Calculator: Zero to Advanced 🚀

**Created by Ujjwal Singh**

Welcome to my C++ Calculator project! Is repository me maine C++ calculator ko bilkul **Zero se Advanced Level** tak step-by-step develop kiya hai. Yeh ek console-based project hai jisse C++ ke concepts ko practice aur strong kiya jata hai.

A step-by-step C++ calculator project journey from zero to advanced levels, featuring switch-cases, functions, loops, history, and dynamic memory.

---

## 📌 Project Roadmap & Levels

- **Level 1: Basic Console Calculator (Single Run)**
  * **Concepts Used:** `switch-case`, `if-else`, basic input/output (`cin`/`cout`).
  * **Features:** Yeh ek simple console-based calculator hai jo do numbers par basic arithmetic (+, -, *, /) perform karta hai. **Note:** Isme calculation hone ke baad program close ho jata hai, isliye har nayi calculation ke liye aapko program ko baar-बार (manually re-run) karna padega.

- **Level 2: Continuous Calculator with Loops & Functions**
  * **Concepts Used:** `while loop`, `Functions`, `Function Overloading`.
  * **Features:** Clean code architecture ke sath-sath isme loop (`while` loop) ka use kiya gaya hai. Isse aapko baar-बार program run nahi karna padega; yeh khud-b-khud aapse dobara input aur variables maangta rahega jab tak aap exit na karna chahein.

- **Level 3: History Feature**
  * **Concepts Used:** `Arrays` / `Structs`.
  * **Features:** Stores past calculations and displays user history.

- **Level 4: History Management**
  * **Concepts Used:** Loops, Data manipulation.
  * **Features:** View history, clear history, and search past calculations.

- **Level 5: Advanced Operations & Multiple Inputs**
  * **Concepts Used:** `<cmath>` library, vectors/arrays.
  * **Features:** Square root, power, cube root, and calculations with multiple numbers.

- **Level 6: Dynamic Memory Allocation**
  * **Concepts Used:** Pointers, `new` / `delete` keywords, Dynamic Arrays.
  * **Features:** Efficient memory usage and flexible data storage.

---

## 🛠️ How to Run
1. Clone the repository: `git clone <your-repo-link>`
2. Compile any level file (e.g., Level 1): `g++ level1_calculator.cpp -o level1`
3. Run the executable: `./level1`
